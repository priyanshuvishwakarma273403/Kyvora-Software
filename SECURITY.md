# Kyvora Security Policy

The Kyvora team takes the security of our development ecosystem, user data, and codebases seriously.

## Supported Versions

| Version | Supported          |
| :---    | :---:              |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a potential security flaw in Kyvora Studio, the Kyvora Collaboration Backend, or the Kyvora Web Portal:

1. **Email:** Send details directly to `security@kyvora.io` (or reach out via private maintainer channels).
2. **Details:** Include a clear description of the issue, severity assessment, affected components, and reproducible steps or PoC.
3. **Timeline:** We will acknowledge receipt of your report within 24 business hours and aim to release a coordinated patch within 7 business days.

For more information, please read our complete [Security & Governance Policy](docs/SECURITY.md).
